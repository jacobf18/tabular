# Categorical OpenML experiments (unmaintained)

Older scripts for imputing mixed-type OpenML datasets. They are not part of the
paper or of `run_benchmark.py` / `make_figures.py`, and they have not been updated
for the current `tabimpute` package (e.g. `get_openml_categorical_errors.py`
imports classes that no longer exist). The dataset list in
`download_openml_categorical.py` matches the datasets in `auc_table.tex`.
